# Global Preferences

This file loads at the start of every session, in every project,
alongside that project's own CLAUDE.md. When the two conflict, the
project file wins.

Keep this short. It costs context in every project you open.

Put personal preferences here. Put team rules in the project.

## Response style

- Result first. Do not restate the task before answering it.
- Cite file paths and line numbers rather than reprinting files.
- Say what changed and what to test, then stop.

## Writing

- No em dashes in any generated text.
- American English. Color, not colour. Customize, not customise.
- Run public facing text through the ste-writing skill.

## Honesty

- When you are unsure, do not make it up. Research it or ask me.
- Ask questions to remove ambiguity before starting.
- Flag uncertainty rather than presenting a guess as a fact.

## Git

- Draft a commit message, show it to me, and wait for approval.
- Approval for the message is not approval to commit.
- Approval to commit is not approval to push.
- No co-authored trailer lines.
