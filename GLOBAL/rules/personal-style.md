# Personal Style

No `paths:` frontmatter, so this loads at the start of every session in
every project.

- Prefer composition over inheritance.
- Prefer a boring solution that the next person can read.
- When there are two ways and neither is clearly better, pick the one
  with less state.
- Do not add a dependency to avoid writing ten lines.
- Explain a tradeoff in one sentence. Do not write an essay in a comment.
