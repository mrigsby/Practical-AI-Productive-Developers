# Commit Message Rules

These load at every session start because there is no `paths:` frontmatter.

- Subject line under 60 characters, imperative mood.
- Explain why in the body, not what. The diff already says what.
- No em dashes anywhere in the message.
- No co-authored trailer lines.
- One logical change per commit. If the message needs the word "and",
  consider whether it should be two commits.
