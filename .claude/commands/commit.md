Draft a commit message for the staged changes.

1. Run `git diff --staged` and read it.
2. Draft the message. Subject line under 60 characters, imperative mood.
   The body explains why, not what.
3. Revise the message with the ste-writing skill.
4. Display the final message for me to review, revise, or approve.
